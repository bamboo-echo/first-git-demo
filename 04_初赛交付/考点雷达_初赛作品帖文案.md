# 考点雷达 · 初赛作品帖文案

## 作品标题

考点雷达 —— 期末复习优先级决策系统

## 一句话介绍

上传你的历年真题、课件、目录和考试范围，考点雷达帮你算出「现在最该先复习什么」，并在时间不够时自动生成极速版、标准版、补充版三条路线。

## 作品背景

大学生期末周普遍存在三种困境：

- 资料多：真题、PPT、笔记、目录散落在各个群聊和文件夹里。
- 时间紧：明天考试和一周考试，复习策略完全不同。
- 抓不住重点：不知道老师强调的内容和真题重复考点哪个更该优先。

考点雷达试图把「复习决策」这件事从经验判断变成可计算、可执行的产品流程。

## 核心功能

1. 课程容器：围绕单门课程统一管理考试时间、剩余时长、目标、范围和备注。
2. 资料资产层：支持历年真题、老师课件、教材目录、考试范围、课堂笔记、指定习题六类资料的新增与本地文件上传。
3. 分析引擎：根据已就绪资料推理题型结构、高频考点、来源依据，并给出分析强度评分。
4. 计划生成层：同一份分析结果按不同时间约束投影为极速版、标准版、补充版三种复习路径。
5. 学习执行层：标记任务完成状态，自动联动剩余内容补全列表。

## 产品亮点

- 以课程为中心，而不是以文件为中心。
- 以复习决策为核心价值，而不是资料总结。
- 极速版 / 标准版 / 补充版建立在同一分析结果上，避免三套割裂内容。
- 来源依据透明，不给黑盒结论。

## 技术栈

React + TypeScript + Vite，纯前端实现，便于快速验证与迭代。

## 作品地址

本地开发版本位于 `kaodian-radar-app/` 目录，运行 `npm run dev` 即可预览。

## 体验入口

1. 打开首页后，课程容器已预填「软件工程」样例数据。
2. 在「资料资产层」新增资料或上传本地文件。
3. 点击「发起分析」查看题型结构、高频考点与来源依据。
4. 切换极速版 / 标准版 / 补充版，观察复习路径随时间约束变化。
5. 标记任务完成，查看剩余内容补全如何联动更新。
6. 在侧边栏切换「数据结构」演示课程，验证分析引擎对多课程的适应性。

## TRAE 开发说明

本项目使用 TRAE IDE 完成，核心开发过程包括：

- 通过 TRAE 浏览器调研大赛官网与社区要求。
- 使用 TRAE Work 生成高视觉质量的报名 HTML。
- 在 TRAE Agent 模式下完成产品骨架设计、组件拆分、分析引擎实现与浏览器验证。
