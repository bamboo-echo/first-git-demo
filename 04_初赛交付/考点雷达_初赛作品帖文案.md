# 考点雷达 · 初赛作品帖文案

## 作品标题

考点雷达 —— 期末复习优先级决策系统

## 一句话介绍

上传你的历年真题、课件、目录和考试范围，考点雷达帮你算出「现在最该先复习什么」，并在时间不够时自动生成极速版、标准版、补充版三条路线。

## 作品背景

大学生期末周普遍存在三种困境：

- 资料多：真题、PPT、笔记、目录散落在各个群聊和文件夹里。
- 时间紧：明天考试和一周考试，复习策略完全不同。
- 抓不住重点：不知道老师强调的内容和真题重复考点哪个更该优先。

考点雷达试图把「复习决策」这件事从经验判断变成可计算、可执行的产品流程。

## 核心功能

1. 课程容器：围绕单门课程统一管理考试时间、剩余时长、目标、范围和备注。
2. 资料资产层：支持历年真题、老师课件、教材目录、考试范围、课堂笔记、指定习题六类资料的新增与本地文件上传。
3. 分析引擎：根据已就绪资料推理题型结构、高频考点、来源依据，并给出分析强度评分。
4. 计划生成层：同一份分析结果按不同时间约束投影为极速版、标准版、补充版三种复习路径。
5. 学习执行层：标记任务完成状态，自动联动剩余内容补全列表。

## 产品亮点

- 以课程为中心，而不是以文件为中心。
- 以复习决策为核心价值，而不是资料总结。
- 极速版 / 标准版 / 补充版建立在同一分析结果上，避免三套割裂内容。
- 来源依据透明，不给黑盒结论。
- 免登录即可体验，零门槛上手。
- 三种主题（星海风 / 童话风 / 像素风）实时切换，玻璃拟态 UI 设计。

## 技术栈

React + TypeScript + Vite + NestJS + Prisma，前后端一体化实现，支持 JWT 账号体系、课程数据持久化、分析与计划生成。

## 体验入口

1. 打开公网地址，点击「🚀 免登录直接体验」即可进入课程工作台（无需注册）。
2. 也可注册/登录账号，数据将持久化保存。
3. 创建课程，填写考试时间、复习目标和考试范围。
4. 在「资料管理」中添加真题、课件、目录、笔记等资料，并标记整理状态。
5. 点击「重新分析」生成题型结构、高频考点、来源依据和准备度评分。
6. 切换极速版 / 标准版 / 补充版，查看不同时间约束下的复习路线。
7. 在「执行清单」中勾选任务，观察剩余内容补全联动更新。
8. 在「历史归档」中查看每次分析留下的快照。
9. 左侧边栏底部可切换三种主题风格。
