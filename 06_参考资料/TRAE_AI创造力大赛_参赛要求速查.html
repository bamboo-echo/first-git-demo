一、赛事总览

TRAE AI 创造力大赛鼓励参赛者使用 TRAE Work 或 TRAE IDE，将创意做成能运行、能体验的 AI 作品。报名和初赛在社区完成发帖，复赛继续完善为完整产品，决赛为线下路演。

个人参赛 使用 TRAE Work / TRAE IDE 可体验 Demo 需证明创作过程真实

二、报名要求

  • 报名位置：TRAE 官方中文社区“大赛报名专区”。
  • 报名时间：2026 年 6 月 16 日 00:00 至 7 月 15 日 23:59。
  • 报名方式：发一篇“创意提案”帖，即为提交报名。
  • 标签要求：四选一：生活娱乐 / 学习工作 / 社会服务 / 硬件交互；如参加公益附加赛题，可加选社会公益。
  • 标题格式：报名赛道 + 创意名称。
  • 正文要求：不少于 100 字，至少包含 4 个部分。
  • 附件要求：必须上传 TRAE Work 生成的创意产物 HTML 文件。

三、报名帖正文模板

  • 1. 创意名称 + 创意介绍：说明想解决的问题、为什么想到做这个、大概是什么产品。
  • 2. 目标用户及痛点：说明面向哪些用户、什么场景下使用、当前有什么不方便。
  • 3. 价值与意义：从商业价值、效率提升、社会价值中选择 1–2 个角度说明。
  • 4. 创意产物 HTML 文件：直接把 HTML 上传到社区报名帖中。

注意：社区发帖成功不等于审核通过，官方每个工作日审核报名帖。

四、初赛 Demo 提交要求

参赛前提
初赛作品有效的前提是报名审核已通过。
提交位置
到“大赛初赛专区”发布 Demo 作品帖。
Demo 形态
需要可交互、能体验；可提供公开体验链接，或将交互式 HTML 用 Zip 打包上传。
赛道一致
初赛标签需与报名通过的赛道保持一致。
过程证明
需展示用 TRAE 完成 Demo 开发的完整流程。
关键材料
不少于 3 张关键步骤截图 + 不少于 3 个关键任务 Session ID。

五、初赛作品帖模板

  • 1. Demo 简介：是什么、面向谁、2–3 个核心功能，建议配截图。
  • 2. Demo 创作思路：灵感来源、想解决的问题、为什么做这个方向。
  • 3. Demo 体验地址：公开体验链接 / Zip 打包 HTML / 硬件演示视频。
  • 4. TRAE 实践过程：关键步骤截图不少于 3 张，Session ID 不少于 3 个。
  • 最后补充：附上已经通过审核的社区报名帖链接。

六、评审与晋级重点

  • 基本要求：Demo 与报名创意方向一致，基于 TRAE IDE 或 TRAE Work 完成。
  • 可体验：提供可体验地址或 HTML 文件，能清晰展示核心功能与目标场景。
  • 结构完整：帖子结构清晰，便于评审理解。
  • 真实过程：展示任务拆解、关键 Prompt / 操作、踩坑与解决过程。
  • 原创合规：内容原创，版权清晰，不包含违法违规或侵权内容。

七、赛事时间线

提交创意，创作并提交可体验 Demo。报名通过后可领取速通奖励，并进入初赛评审。
